# 安全与限制

## 公开范围

本仓库只公开：

- 可运行的应用源码与配置模板。
- 产品说明与架构设计。
- 可单独发送的系统图。
- 演示脚本、演示视频入口和访谈说明。

不公开：

- 第三方课程资料、内部制度和未获授权的示例文档。
- `.env`、API Key、Token、Cookie 或登录凭据。
- 运行日志、向量数据库、缓存和历史会话。
- 包含真实用户信息的截图或录屏。

## 密钥处理原则

1. 密钥不写入 README、视频、截图、提交记录或日志。
2. 本地开发使用 `.env`，仓库只保留脱敏后的 `.env.example`（本展示仓库不需要保留）。
3. 生产部署使用平台级 Secret 管理，并限制调用权限。
4. 凭据一旦被怀疑暴露，应立即撤销并轮换，而不是只删除可见字符串。
5. 为密钥设置配额、费用告警和最小权限，控制异常调用带来的影响。

## 当前已知限制

### RAG 文档问答

- 复杂 PDF、扫描件和表格解析仍需专门优化。
- 当前演示未接入独立重排模型，原因是第三方重排服务的免费额度已经用完；这不代表重排没有价值，后续需通过对比测试评估恢复条件。
- 评估结果取决于测试集质量，暂无公开的统一效果分数。
- 当前为单机演示方案，尚未实现企业级权限隔离与多租户。

### 命理 Agent

- 依赖外部模型、搜索和工具服务，网络与配额会影响体验。
- 工具选择准确率需要持续用典型问题和异常输入验证。
- 命理内容仅用于交互演示，不构成现实决策建议。

## 后续生产化方向

- 增加自动化测试：文档解析、检索、工具路由、异常输入和拒答。
- 增加可观测性：检索耗时、模型延迟、工具调用成功率与费用。
- 增加安全控制：密钥托管、限流、审计、输入过滤和输出边界。
- 增加产品指标：首次成功率、有效回答率、人工修正率和用户反馈闭环。
